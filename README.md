# PF2e Companion (No Python Required)

This repository now includes a lightweight **desktop-friendly web app** you can run on Windows without installing Python.

## Quick start (Windows)

1. Download or copy this folder to your Windows machine.
2. Double-click `Launch-PF2e-App.bat`.
3. Your default browser opens the app.

## What it includes

- **Session Notes**: simple note pad with local auto-save.
- **Encounter XP Helper**: quick XP totals by enemy levels.
- **Loot Tracker**: add and remove loot entries during play.
- **Party Checklist**: prep checklist with saved progress.

## Storage

The app stores data locally in your browser (`localStorage`) so it works offline and does not require a backend.

## Files

- `Launch-PF2e-App.bat` – one-click launcher for Windows
- `app/index.html` – app UI
- `app/styles.css` – app styling
- `app/app.js` – app logic
